# Evidencia ESP32

- `uart-bridge-build.log` y `ble-test-build.log` conservan la compilación
  de los perfiles con ESP-IDF v5.5.6 y target `esp32`. Las rutas del SDK
  se representan mediante marcadores.
- `framing-c.log` registra la prueba C del cierre: reconstrucción,
  desbordamiento, FIFO, reconexión, generación y fragmentación.
- [Evidencia de interoperabilidad HB1](../../shared/evidence/README.md).

La entrega de notificaciones por radio y el funcionamiento eléctrico
se registran durante las pruebas físicas.
