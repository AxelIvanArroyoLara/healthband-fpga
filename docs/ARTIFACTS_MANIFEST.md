# Manifiesto de entregables

Todas las rutas del inventario parten de la raíz del repositorio. Los
binarios de Android y ESP32 se distribuyen en
`deliverables/healthband-final-testing.zip`. Los APK y las imágenes ESP32
están excluidos de Git. El clon conserva fuentes, reportes, scripts y sumas.

- **Android** — Para regenerar, ejecuta desde `mobile/`
  `./gradlew :app:assembleDebug :app:assembleRelease`. Los APK quedan en
  `mobile/app/build/outputs/apk/`. Copia ambos a `mobile/artifacts/`.
- **ESP32** — Compila ambos perfiles con [ESP-IDF v5.5.6](../esp32/README.md).
  Copia de cada salida la aplicación, bootloader, tabla, `flash_args`
  y configuración resuelta. Conserva los offsets emitidos por el SDK.
- **Reempaquetado** — Con los artefactos de esta versión, comprueba
  `shasum -a 256 -c SHA256SUMS.txt` desde cada carpeta de artefactos.
  Si regeneras binarios con otra firma o versión, actualiza las sumas y
  la procedencia y confirma los manifiestos. Desde la raíz ejecuta
  `python3 shared/package_testing.py`. El script verifica las sumas antes
  de crear el ZIP y comprueba el archivo terminado.
- **FPGA** — El SOF se incorpora tras síntesis y temporización. Consulta el
  [procedimiento Quartus](../fpga/artifacts/README.md).
- **Evidencia física** — Registrar durante las pruebas con
  [la guía](PHYSICAL_INTEGRATION_GUIDE.md) y el [checklist](PHYSICAL_TEST_CHECKLIST.md).
