# Detección personalizada

Este módulo reunirá la experimentación para detectar anomalías respecto de la
línea base individual de cada usuario.

## Responsabilidades

- Definir, junto con la aplicación, las características derivadas de BPM, IBI
  y calidad.
- Evaluar métodos experimentales sin presentar resultados como diagnóstico.
- Diseñar validaciones reproducibles y trabajar con datos locales anonimizados.
- Integrar únicamente resultados acordados con `mobile/`.

El algoritmo de anomalías y sus métricas de aceptación están pendientes. No se
incluyen modelos ni dependencias en esta etapa.
